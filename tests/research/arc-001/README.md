# ARC-001 executable research evidence

This directory contains maintained, executable copies of the apparatus used by
ARC-001. These are architectural-research artifacts, not ordinary SemTL API
contract tests, and they do not independently define supported production
behavior.

## Layout

- `common/` contains the frozen consumer, stable stored subject, semantic
  oracle, and calibration test shared by the comparison.
- `a01-owning-value/` preserves the generated by-value attempt. A01 is
  INCONCLUSIVE as the controlled ARC result and retained as Exploratory
  engineering evidence.
- `a02-ephemeral-proxy/` preserves the conforming generated ephemeral-proxy
  attempt accepted as Controlled evidence supporting H-A within scope.
