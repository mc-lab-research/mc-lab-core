# Contributing to mcLab

Thank you for your interest in mcLab.

## Current status

> **mcLab is not currently open to external code contributions.**

The project is still establishing its architecture, terminology, and initial semantic foundations.

Please do not submit unsolicited pull requests or major implementation proposals at this stage.

## What is welcome

The following are appreciated:

- documentation corrections;
- feedback on clarity;
- relevant research references;
- expressions of interest in future contribution.

## Project direction

mcLab follows this dependency direction:

**Tools → Extensions → Core**

The Core should remain portable, language-independent, and headless.

The project vision is described in [README.md](README.md).

## Later contributions

External contributions may open once the architecture, public contracts, build, testing, and review processes are sufficiently stable.

This document will be updated when pull requests are accepted.
