## Root-cause fix (issue #51)

Three consecutive Scorecard runs failed during setup because the pinned SHA for `ossf/scorecard-action` was a typo:

| | SHA |
| --- | --- |
| **Broken (used in failed runs)** | `f49aabe0b5af0936a0987cfb85d86b75b3f1e7b2` |
| **Correct v2.4.1 commit** | `f49aabe0b5af0936a0987cfb85d86b75731b0186` |

The last eight hex characters differed (`b3f1e7b2` → `731b0186`). GitHub Actions reported "unable to find version" for the unresolvable SHA, so analysis and SARIF publication never began.

Failed runs prior to fix:
- https://github.com/mc-lab-research/mc-lab-core/actions/runs/30815369119
- https://github.com/mc-lab-research/mc-lab-core/actions/runs/30815651395
- https://github.com/mc-lab-research/mc-lab-core/actions/runs/30817406839
